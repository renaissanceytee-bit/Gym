# ASCEND

A first interactive web MVP for the ASCEND fitness and self-improvement app.

## Run it

Open `index.html` in a modern browser. No build step or package installation is required. An internet connection loads the optional Google Fonts; the app itself runs locally.

## In this first slice

- Responsive, dark-themed fitness dashboard.
- Progress cards for score, weekly workouts, streak, and XP.
- Daily mission checklist with XP feedback.
- Workout logging form and recent workout list.
- Browser-local demo state saved with localStorage.

## Current limits

This is a front-end prototype. It does not yet include user accounts, cloud sync, nutrition entry, a real scoring system, AI coaching, social features, or payments. Dashboard sample values are illustrative. Do not use it to store sensitive health information.
